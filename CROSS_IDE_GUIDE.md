# Cross-IDE Skill Router Guide

This guide explains how to use the Skill Router with different AI coding environments.

## Supported Environments

### 1. Claude Code (Native) ⭐
**Installation:**
```bash
git clone https://github.com/z99wE/skill-router.git ~/.claude/skills/skill-router
python3 ~/.claude/skills/skill-router/scripts/scan-skills.py
```
**Usage:** The router auto-fires on every prompt with 30s debounce. Type `/skill-router <query>` for manual search.

---

### 2. Cursor
**Installation:**
```bash
# Generate Cursor rules
python3 ~/.claude/skills/skill-router/adapters/generate_all.py \
  --ide cursor \
  --output ~/.cursor
```
**Generated Files:**
- `.cursor/rules/skills.md` — Main skill index
- Individual skill markdown files in `.cursor/rules/`

**Usage:** Cursor will recognize `skills.md` as reference material. Use the slash commands from Claude Code directly.

---

### 3. VS Code with Copilot
**Installation:**
```bash
python3 ~/.claude/skills/skill-router/adapters/generate_all.py \
  --ide vscode \
  --output ~/your-project
```
**Generated Files:**
- `package.json` — Extension manifest with skill commands
- Can be packaged and published as VS Code extension

---

### 4. GitHub Copilot (Chat/Inline)
**Installation:**
```bash
python3 ~/.claude/skills/skill-router/adapters/generate_all.py \
  --ide copilot \
  --output ~/your-repo
```
**Generated Files:**
- `.github/copilot-instructions.md` — Context for Copilot
- Contains skill shortcuts and usage patterns

**Usage:** Copilot reads `.github/copilot-instructions.md` automatically. Mention `/skill-router` in your prompts.

## Quick Generate All

```bash
# Generate adapters for all supported IDEs at once
python3 ~/.claude/skills/skill-router/adapters/generate_all.py --output ~/all-adapters
```

This creates:
- `~/.cursor/rules/skills.md`
- `~/.byNara/rules/skills.md`
- `~/.opencode/skills/*.md`
- `~/.watsonx/agents/manifest.json`
- Plus project-level files in `~/all-adapters/`

---

## How It Works

1. **Canonical Source**: All adapters read from `skill_index.csv` (generated by `scan-skills.py`)
2. **Transformation**: Each adapter converts the same data into its target format
3. **Sync**: Run `generate_all.py` after adding/removing skills to update all IDEs
4. **Limitations**: Some IDEs have row limits (e.g., 20-30 skills max) due to context constraints

---

## Adding New IDE Support

To add support for another IDE:

1. Create `adapters/<ide>_adapter.py` following the pattern:
   ```python
   def generate_<ide>(skills, output_dir):
       # Transform skills into target format
       # Return list of generated paths
       pass
   ```

2. Register in `generate_all.py`:
   ```python
   adapters["<ide>"] = generate_<ide>
   ```

3. Update README.md with the new IDE in the compatibility table

## Troubleshooting

**Problem**: Skills not showing in [IDE]
- Check that the adapter ran successfully
- Verify the generated files are in the right location
- Restart the IDE to reload configuration

**Problem**: Too many skills for [IDE]
- Most IDEs have context limits
- Adapters automatically cap at 20-30 skills
- Adjust in the adapter script if needed

**Problem**: Want different top skills per IDE
- Filter in `generate_all.py` before passing to specific adapter
- Or manually edit the generated files (they're meant to be customized)
