# Cross-IDE Skill Adapters

This directory contains format converters to make the skill index compatible with different AI coding environments.

## Supported IDEs

| IDE | Format | Adapter |
|-----|--------|---------|
| Claude Code | SKILL.md + hooks | Native (already supported) |
| Cursor | .cursorrules / custom skills | `cursor_adapter.py` |
| VS Code | extensions.json + snippets | `vscode_adapter.py` |
| GitHub Copilot | .github/copilot-instructions.md | `copilot_adapter.py` |
| OpenCode/Antigravity | .opencode/skills/ | `opencode_adapter.py` |
| Codex CLI | codex.yaml | `codex_adapter.py` |
| IBM Watsonx Orchestrate | watsonx_skills/ | `ibm_adapter.py` |

## Usage

```bash
# Generate adapters for all supported IDEs
python3 adapters/generate_all.py --source ~/.claude/skills/skill-router/references/skill_index.csv

# Generate specific adapter
python3 adapters/cursor_adapter.py --input skill_index.csv --output .cursor/rules/skills.md

# Preview what would be generated
python3 adapters/generate_all.py --dry-run
```

## How It Works

1. **Read** the canonical skill_index.csv (generated by scan-skills.py)
2. **Transform** each skill entry into the target IDE's format
3. **Output** files in the correct location for that IDE
4. **Maintain** bi-directional sync so updates propagate
